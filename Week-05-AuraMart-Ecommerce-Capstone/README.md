## Project Overview
AuraMart is a modern E-Commerce Single Page Application (SPA) built with vanilla JavaScript. It includes client-side hash routing, an interactive product catalog with search and filters, a slide-out cart drawer, wishlist support, promo code discounts, and a simulated checkout flow with printable order invoices.

### Key Features:
1. **Client-Side SPA Routing:**
   - Hash-based router (`#/home`, `#/products`, `#/product/:id`, `#/cart`, `#/checkout`, `#/order-success`, `#/wishlist`).
   - Smooth navigation between views without page reloads.
2. **Product Catalog & Filtering:**
   - Real-time search across product names and descriptions.
   - Category filtering (Audio, Electronics, Wearables, Home & Living, Accessories).
   - Price range slider and sorting options (Price Low-to-High, High-to-Low, Rating).
3. **Cart & Wishlist:**
   - Slide-out shopping cart drawer accessible from any page.
   - Item quantity controls and easy removal.
   - Free shipping calculation with dynamic threshold indicator.
   - Promo discount codes (e.g. `SAVE20` for 20% off).
   - Wishlist toggle with badge counter.
4. **Checkout & Invoice:**
   - Multi-step checkout form with shipping address and payment method selection.
   - Order confirmation screen with printable invoice.
