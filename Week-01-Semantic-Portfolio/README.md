## Project Overview
This project is a multi-page personal portfolio website built with HTML5 semantic elements and accessible markup. It includes Home, About, Projects, and Contact pages, following semantic HTML and accessibility best practices.

### Features:
1. **Semantic HTML5 Structure:**
   - Uses proper semantic layout tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`).
   - Text elements include `<figure>`, `<figcaption>`, `<time>`, and `<address>`.
2. **Accessibility & Usability:**
   - Keyboard accessible skip link (`Skip to main content`).
   - Proper form labeling (`<label for="...">`) and structured fieldsets.
   - High-contrast accessible color scheme and visible focus outlines.
3. **Multi-Page Layout:**
   - `index.html` — Homepage with introduction and featured projects.
   - `about.html` — Background, skills, and education.
   - `projects.html` — Project showcase list.
   - `contact.html` — Contact form with client-side validation.
